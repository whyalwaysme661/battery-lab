# Battery Lab

面向电池材料学习与数据阅读的交互工作台。覆盖太阳能、二次、一次、燃料与核电源，提供材料选择、三维结构、分段原理讲解和实测数据计算。

目前包含 **32 个体系、178 项材料选择和 57 个预制三维模型**。界面支持中文/英文、桌面操作、手机适配与键盘访问。

## 快速开始

需要 Node.js 22 或更新版本和现代浏览器。

```bash
git clone https://github.com/whyalwaysme661/battery-lab.git
cd battery-lab
npm run dev
```

打开 <http://127.0.0.1:8877/>。浏览器运行文件和 Three.js 已随仓库提供，直接预览无需安装依赖，也不需要 Blender。停止预览使用 `Ctrl+C`。

```bash
npm run check
npm run credits:check
```

第一条检查材料兼容规则、计算、曲线、图片、双语内容、首页交互与全部 GLB 模型；第二条检查资源署名清单是否与图片清单一致。

## 如何使用

1. **选择体系**：从电池类别进入具体体系。不同储能电池、燃料电池和光伏采用对应的功能层与计算。
2. **配置材料**：搜索和选择电极、电解质及可选界面层。研究配方按兼容组合切换，图片区分真实试样、原料参考、文献参考和示意。
3. **查看结构**：旋转、展开、逐层查看或隔离部件；分段讲解展示反应、内部载流子及外部路径。所有模型已预制。
4. **测量与评估**：教学滑杆用于理解面积与电流密度；输入自己的同工况测量数据后，计算电流密度、工作点功率、能量与比能量。光伏计算工作点效率。
5. **阅读循环曲线**：粘贴或导入 `cycle,capacity_mAh` 两列 CSV；评价容量保持率及已测区间内首次阈值交点。
6. **对照与导出**：固定方案 A/B，核对条件，导出参数、原始输入、评估结果、待验证计划与来源。

当前页面中的测量草稿按完整配置保存；刷新前需要导出。项目目前不提供账号或云端保存。

## 数据与模型的边界

- 文献结果绑定原始试样、条件或产品，不能用来预测任意自选配方。
- 循环曲线只在实测覆盖范围内解读；阈值交点采用相邻点线性内插，不外推寿命。
- 教学示例与实测数据分开，示例不进入实测记录、方案对照或实测导出。
- 安全检查展示机制、触发条件和所需测试，不表示电池已通过安全认证。
- 三维结构和原理动画用于观察与讲解。内部层厚、重复层数和表面纹理不作为制造参数；播放节奏不代表实际传输速度。
- 材料照片保留对象、比例尺、来源及许可。原料和同路线文献参考不冒充当前完整配方的实拍。

## 项目结构

```text
dist/                       可直接托管的静态网站
  assets/materials/         材料图片、缩略图、示意图与来源清单
  assets/fonts/             本地字体及 OFL 许可证
  models/                   预制 GLB 模型
  vendor/                   Three.js 浏览器模块及许可证
tools/                      校验、署名生成、模型制作与发布准备脚本
LICENSE                     自有代码的 MIT 许可证
THIRD_PARTY_NOTICES.md       第三方资源署名与许可范围
```

核心数据在 `dist/catalog.js`，计算在 `dist/analysis.js`，图片映射在 `dist/imagery.js`。界面和模型交互从 `dist/app.js` 进入。

## 修改与贡献

修改材料时一并提供原始来源、适用条件和兼容组合。新增图片需确认对象与转载许可，在 `dist/assets/materials/manifest.json` 记录作者、出处和修改说明，并提供中英文图注。真实显微图片不使用生成式修图重绘纹理。

图片清单变更后运行：

```bash
npm run credits
npm run check
npm run credits:check
```

可通过 Issue 描述问题，或通过 Pull Request 提交修改。请说明用户可观察到的变化和验证方式。

模型生成代码位于 `tools/blender-model.py`，批量导出入口为 `tools/export-models.py`。使用 Blender 的 Python 环境运行；已有模型可直接使用，普通网页贡献无需重新导出模型。导出器会将可编辑 `.blend` 工程保存在项目父目录，该工程不属于网页运行资源。

## 静态托管

把 `dist/` 作为网站根目录提供 HTTP 服务即可。页面资源使用以 `/` 开头的路径，需要部署在域名根路径；GitHub 项目 Pages 的 `/battery-lab/` 子路径需要先处理资源路径，不能直接按现状上传即用。
